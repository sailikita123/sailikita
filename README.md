# 🚕 Sawaari — Ride Booking Application

Sawaari is a ride-booking mobile application prototype inspired by modern mobility platforms.

The application demonstrates rider and driver workflows, OTP-based authentication and location-oriented ride interactions.

## 🚀 Features

* 👤 Rider registration and login
* 🚗 Driver workflow
* 🔐 OTP-based authentication
* 🗺️ Location and map interactions
* 🏍️ Bike and auto ride options
* 📱 Mobile-first interface
* 🚕 Ride booking workflow

## 🛠️ Tech Stack

* React Native
* Expo
* JavaScript

## 🔄 Application Flow

```text
User
 ↓
Login / OTP
 ↓
Select Ride
 ↓
Choose Pickup & Destination
 ↓
Select Vehicle
 ↓
Book Ride
 ↓
Driver Assignment
 ↓
Ride
```
